# LokaMeet — гайд для новичка

**Актуально для версии 1.4.0.**

**Для кого этот файл:** человек, который плохо знаком с программированием, но хочет понять проект и **знать, в какую папку и в какой файл заходить**, если нужно поменять интерфейс, логику, звук, сеть, звонки и т.д.

**Где лежит проект на диске:**  
корневая папка репозитория — та, где лежит `package.json` (например `LokaMeet/`)

**Как открыть файл в редакторе кода:** слева в проводнике файлов найдите имя файла и кликните по нему.  
Или нажмите `Ctrl+P` и начните печатать имя файла (например `App.tsx`).

## 1. Что это за программа (простыми словами)

**LokaMeet** — это программа для звонков и чата **внутри одной локальной сети** (Wi‑Fi / кабель в офисе или дома).  
Интернет для звонка **не нужен**: компьютеры находят друг друга в сети и передают звук/видео напрямую.

В программе есть:

- список людей в сети;
- звонок одному человеку;
- конференция (несколько человек);
- чат и файлы;
- демонстрация экрана;
- игры во время звонка (шашки, шахматы, морской бой);
- настройки (камера, микрофон, звуки, внешний вид, игры).

## 2. Самая важная мысль: программа состоит из 3 «слоёв»

Представьте дом:

| Слой | Простыми словами | Папка |
|------|------------------|--------|
| **Окно (интерфейс)** | То, что вы видите: кнопки, чат, видео, настройки | `src\renderer\` |
| **Мост** | Переводчик между окном и «движком». Окно само не лезет в системные вещи | `src\preload\` |
| **Движок (сердце)** | Сеть, поиск людей, сервер сигналов, сохранение настроек, логи | `src\main\` |

Ещё есть общая «тетрадь правил» для всех слоёв:

| Папка | Зачем |
|-------|--------|
| `src\shared\` | Общие названия данных (кто такой пользователь, какое сообщение и т.д.) |

**Правило для новичка:**

- Меняете **кнопки, цвета, тексты, поведение в окне** → почти всегда `src\renderer\`
- Меняете **поиск в сети, сервер, сохранение на диск** → `src\main\`
- Добавляете **новую «команду» из окна к движку** → и `main`, и `preload`

### Чего новичок обычно НЕ трогает

| Папка / файл | Почему |
|--------------|--------|
| `node_modules/` | Тысячи чужих библиотек. Сломается установка |
| `dist/` | Пересоздаётся при сборке. Правки пропадут |
| `release/` | Готовый установщик |
| `package-lock.json` | Служебный файл npm |

## 5. Папка `src\main\` — ДВИЖОК (сеть, сервер, диск)

Окно само не умеет «слушать сеть» и «писать файл настроек» напрямую. Это делает **main**.

### 5.1. Файлы

| Файл | Полный путь | За что отвечает |
|------|-------------|-----------------|
| **main.ts** | `src\main\main.ts` | **Старт программы:** открыть окно, запустить сервер и поиск в сети, настройки по умолчанию |
| **ipc.ts** | `src\main\ipc.ts` | **Список команд**, которые окно может попросить у движка (получить настройки, подключиться, сохранить профиль…) |
| **storage.ts** | `src\main\storage.ts` | **Сохранение на диск** профиля и истории чата |
| **logger.ts** | `src\main\logger.ts` | **Запись логов** в папку `logs\` |
| **log.ts** | `src\main\log.ts` | Короткие команды для записи в лог (обёртка) |
| **avatarStore.ts** | `src\main\avatarStore.ts` | Сохранение и выдача аватаров пользователя и собеседников |
| **displayMediaPreference.ts** | `src\main\displayMediaPreference.ts` | Запоминание выбранного источника демонстрации экрана |

### 5.2. Подпапки движка

| Файл | Полный путь | За что отвечает |
|------|-------------|-----------------|
| **LanDiscovery.ts** | `src\main\discovery\LanDiscovery.ts` | **Поиск людей и конференций в локальной сети** (mDNS + запасной UDP) |
| **SignalingServer.ts** | `src\main\signaling\SignalingServer.ts` | **Сервер сигналов:** «кто кому звонит», «принять/отклонить», сообщения чата между компьютерами, передача WebRTC‑сигналов |

## 10. Как устроено окно (три колонки)

Когда программа открыта, экран примерно такой:

```
┌──────────────────┬────────────────────────┬──────────────────┐
│  ЛЕВАЯ ПАНЕЛЬ    │  ЦЕНТР (ВИДЕО)         │  ПРАВАЯ ПАНЕЛЬ   │

│  камера/мик,     │  видео собеседников   │                  │
│  пользователи,   │                       │                  │
│  конференции     │                       │                  │
└──────────────────┴────────────────────────┴──────────────────┘
```

Код этих трёх частей — в **`src\renderer\App.tsx`**.  
Внешний вид колонок и полосок‑разделителей — в **`src\renderer\styles.css`**.

## 11. Настройки: какая вкладка → где в коде

Откройте `src\renderer\App.tsx` и ищите `settingsTab`.

| Вкладка в программе | Что там | Где править |
|---------------------|---------|-------------|
| **Медиа** | Качество видео, устройства, размер панели чата | `App.tsx` + иногда `webrtc.ts` |
| **Камера** | Зум, фон, ручные параметры камеры | `App.tsx` + `cameraFx.ts` / `cameraControls.ts` |
| **Аудио** | Громкость, шумодав, звуки mp3 | `App.tsx` + файлы в `snds\` |
| **Интерфейс** | Масштаб, компактность, ширина сайдбара | `App.tsx` + `styles.css` |
| **Игры** | Размер доски, подсказки, звуки партий | `App.tsx` + `src\renderer\lib\games\settings.ts` |
| **Подключение** | Ручное подключение к другому компьютеру по IP и порту | `App.tsx` → `manualConnect` |
| **Помощь** | Встроенная справка по работе в LAN | `App.tsx` |

Кнопка **«Сохранить»** записывает настройки через движок в файл профиля на компьютере (через `storage.ts`).

## 12. Как искать нужное место, если не знаете имя функции

1. Откройте программу и **посмотрите точный текст** на кнопке (например «Позвонить»).
2. В редакторе кода откройте поиск по всему проекту (обычно `Ctrl+Shift+F`).
3. Вставьте этот текст.
4. Чаще всего найдёте:
   - либо строку в `i18n.ts` (перевод),
   - либо использование в `App.tsx`.

Если текст на английском ключе (типа `call`) — ищите ключ в `i18n.ts`, потом этот ключ в `App.tsx`.

## 13. Безопасный порядок работы для новичка

1. **Сделайте копию** файла или запомните, что меняли (или используйте Git, если умеете).
2. Меняйте **по одному** маленькому делу (сначала цвет, потом кнопку).
3. Запускайте проверку:
   ```text
   npm run dev
   ```
   (в терминале в папке проекта).
4. Если программа сломалась — **отмените правку** (`Ctrl+Z` в файле) или верните файл из копии.
5. Папки `dist` и `node_modules` **не редактируйте**.

## 14. Частые задачи — пошагово

### А) Поменять цвет кнопок / фона

1. Откройте `src\renderer\styles.css`
2. В начале файла найдите переменные вроде `--bg`, `--accent`, `--panel`
3. Поменяйте цвет (например `#60a5fa` на другой)
4. Сохраните файл и посмотрите в запущенной программе

### Б) Поменять русскую надпись

1. Откройте `src\renderer\i18n.ts`
2. Найдите нужную фразу в блоке `ru`
3. Измените текст
4. Сохраните

### В) Поменять звук звонка

1. Положите новый файл, например, в `snds\my_ring.mp3`
2. В программе: Настройки → Аудио → «Звук звонка» → укажите путь / выберите файл
3. Нажмите «Сохранить»
4. (Опционально) дефолт в коде: `src\main\main.ts` (поле `callSoundFile`) и состояние в `App.tsx`

### Г) Добавить смайл

1. Положите картинку в папку `smiles\`
2. Пересоберите/перезапустите так, чтобы список обновился
3. Список файлов читает движок: `src\main\ipc.ts` (команда `smiles:list`)

### Д) Изменить качество видео по умолчанию

1. Ограничения размеров: `src\renderer\lib\webrtc.ts` → `getVideoConstraints`
2. Значение по умолчанию в профиле: `src\main\main.ts` (`defaultVideoQuality`)
3. Переключатель в UI: `src\renderer\App.tsx` (настройки Медиа + кнопки «низк./средн./высок.»)

### Е) Люди не находятся в сети

Смотрите не интерфейс, а движок:

1. `src\main\discovery\LanDiscovery.ts`
2. Логи в `logs\`
3. В UI есть подсказка про mDNS — это как раз про discovery

### Ж) Звонок соединяется, но нет звука/видео

Смотрите логику медиа в окне:

1. `src\renderer\App.tsx` → `ensureLocalMedia`, `ensureAudioTrackPresent`
2. `src\renderer\lib\webrtc.ts`
3. Права Windows на микрофон/камеру для приложения

Регрессии после камеры и демонстрации экрана (голос не должен пропадать) — в `QA_CHECKLIST.md`.

## 17. Если совсем не знаете, с чего начать

1. Откройте **`src\renderer\App.tsx`** — это «пульт» того, что видит пользователь.  
2. Откройте **`src\renderer\styles.css`** — если нужно только «покрасить».  
3. Откройте **`src\renderer\i18n.ts`** — если нужно только поменять слова.  
4. В сеть/поиск людей/`движок` лезьте только когда проблема **не** в кнопках и цветах:  
   **`src\main\discovery\`** и **`src\main\signaling\`**.

Более техническое описание смотрите в **`README.md`** в корне проекта и в комментариях рядом с нужным кодом.
